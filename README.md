# Autoscan
This Project is from real company where i used to create a dashboard on real Data.

📊 AutoScan Daily Inspection Dashboard

Project Description:
An interactive Power BI dashboard developed to monitor inspection and quality performance. It provides insights into inspection quantity, OK quantity, rework, hold percentage, rejection PPM, parts, inspectors, and rework reasons.

🎯 Key Objectives
Monitor total quantity checked.
Track OK quantity.
Analyze Rework % and Hold %.
Monitor Total Rejection PPM.
Analyze monthly inspection trends.
Identify high-rework parts.
Compare inspector workload.
Identify major rework reasons.
📌 Dashboard KPIs
Total Qty Checked
Sum of OK Qty
Rework %
Hold %
Total Rejection PPM
🎛️ Filters
Year
Month
Part Name
Inspector Name
📈 Dashboard Visuals
Qty Checked By Month Year → Monthly inspection trend
Part Wise Analysis → Rework PPM by part
Qty Checked by Inspector → Inspector-wise inspection quantity
Qty Checked by Reason of Rework → Major rework reasons
